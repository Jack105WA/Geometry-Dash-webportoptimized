Geometry Dash webport is a version of Geometry Dash adapted to run from a web browser, allowing you to play without having to install the game.

📥 Download and installation
Access this GitHub repository.
Click the button Code, located at the top.
Select Download ZIP to download the files.
Extract the contents of the ZIP file to a folder on your computer.
You now have everything ready to run the game!
▶️How to play
💻 Run from your computer
Open the folder where you extracted the files.
Search the file Geometry Dash Webport.html.
Open it with your preferred web browser.
Click the button Load or press the key Espacio to start loading.
Wait for the game to finish loading.
Enjoy Geometry Dash right from your browser!
Advice: It is recommended to use an updated browser for better compatibility and performance.

⚙️ Requirements
To run Geometry Dash Webport, you need to:

A modern and updated web browser.
JavaScript enabled.
A compatible computer.
Internet connection, game resources require loading from external servers.

⚠️Troubleshooting
If you experience problems running the game, you can try the following solutions:

** Blank screen:** Refresh the page or reopen the HTML file.
**Infinite charging:** Check your Internet connection and wait a few moments.
** Poor performance:** Close unnecessary applications and try another browser.
**The game does not start:**Checks that JavaScript is enabled and tries to use an updated browser.
** Errors loading:** Verifies that all files in the ZIP have been extracted correctly.
If the problems persist, they may be related to the file, browser, or service used to run the webport.
